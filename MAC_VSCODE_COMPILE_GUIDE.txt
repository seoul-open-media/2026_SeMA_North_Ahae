macOS + VS Code 빌드 가이드 (2026_SeMA_North_Ahae)

이 문서는 macOS에서 VS Code로 이 프로젝트를 빌드(컴파일)하기 위한 최소 절차를 설명합니다.
프로젝트 설정 기준:
- 보드: teensymm (Teensy MicroMod)
- 프레임워크: Arduino
- 환경: PlatformIO env = teensymm
- 모터 컨트롤러: Moteus C1
- Aux2 연결: AS5600 + 5V 팬

========================================
1) 사전 준비
========================================

1. Xcode Command Line Tools 설치
터미널에서 아래 명령 실행:

xcode-select --install

이미 설치되어 있으면 "already installed" 메시지가 표시됩니다.

2. Homebrew 설치 (없으면)
https://brew.sh 안내대로 설치합니다.

3. VS Code 설치
https://code.visualstudio.com 에서 macOS 버전 설치

4. Git 설치 확인
터미널에서:

git --version

버전이 출력되면 정상입니다.

========================================
2) 저장소 열기
========================================

1. 원하는 경로로 이동 후 클론:

git clone https://github.com/seoul-open-media/2026_SeMA_North_Ahae.git

2. 프로젝트 폴더 열기:

cd 2026_SeMA_North_Ahae
code .

참고:
- 이미 폴더가 있다면 VS Code에서 해당 폴더만 열어도 됩니다.

========================================
3) VS Code 확장 설치
========================================

VS Code Extensions에서 아래를 설치:
- PlatformIO IDE (플랫폼아이오 공식 확장)

설치 후 VS Code를 재시작하면 환경 인식이 안정적입니다.

========================================
4) 프로젝트 설정 확인
========================================

platformio.ini의 핵심 항목:
- [env:teensymm]
- platform = teensy
- board = teensymm
- framework = arduino

macOS에서 주의할 점:
- monitor_port 값이 Linux 스타일(/dev/ttyACM0)일 수 있습니다.
- 컴파일만 할 때는 monitor_port가 맞지 않아도 빌드 자체에는 영향이 없습니다.

하드웨어 메모:
- Moteus C1의 Aux2 포트에 AS5600과 5V 팬이 연결된 구성을 기준으로 합니다.

========================================
5) 첫 빌드 (컴파일)
========================================

방법 A: VS Code UI 사용
1. 하단 상태바의 PlatformIO 아이콘(집 모양) 클릭
2. PROJECT TASKS -> teensymm -> General -> Build 실행

방법 B: 터미널 사용
프로젝트 루트에서:

platformio run

성공 시 "SUCCESS"와 함께 .pio/build/teensymm 경로에 빌드 산출물이 생성됩니다.

========================================
6) 자주 발생하는 문제와 해결
========================================

1. platformio 명령을 찾지 못함
- VS Code의 PlatformIO 확장을 먼저 설치
- 또는 터미널에서 Python/pip 환경 문제를 점검

2. 라이브러리 다운로드 실패
- 인터넷 연결 확인
- 잠시 후 재시도 (처음 빌드 시 의존성 다운로드 시간이 걸림)

3. 빌드 캐시 꼬임
아래 순서로 정리 후 재빌드:

platformio run -t clean
platformio run

4. Apple Silicon(M1/M2/M3)에서 툴체인 설치 지연
- 첫 실행에서 툴체인 설치 시간이 길 수 있으므로 완료까지 대기

========================================
7) (선택) 시리얼 모니터를 macOS에서 사용하려면
========================================

장치 포트 확인:

ls /dev/cu.*

Teensy 계열은 보통 /dev/cu.usbmodemXXXX 형태입니다.

필요 시 platformio.ini에서 monitor_port를 실제 포트로 수정:

monitor_port = /dev/cu.usbmodemXXXX

모니터 실행:

platformio device monitor --baud 115200

========================================
8) 빌드 확인 체크리스트
========================================

- VS Code에서 프로젝트 루트를 정확히 열었는가
- PlatformIO IDE 확장이 설치되어 있는가
- platformio.ini에 env가 teensymm으로 설정되어 있는가
- 터미널에서 platformio run이 성공하는가

위 4가지가 통과되면 macOS에서 컴파일 환경은 준비 완료입니다.
